# Cross-Site Scripting (XSS) — Web Security Academy

A hands-on cybersecurity learning repository documenting my journey through Cross-Site Scripting (XSS) vulnerabilities using PortSwigger Web Security Academy.

This repository covers the fundamentals of XSS, vulnerability analysis, exploitation techniques, payload breakdowns, practical lab writeups, and mitigation strategies.

The goal is to develop a deeper understanding of how XSS vulnerabilities work, how they can be exploited, and how developers can prevent them.

## Topics Covered

- Reflected XSS
- Stored XSS
- DOM-Based XSS
- Blind XSS
- XSS Contexts
- XSS Filter Bypasses
- Content Security Policy (CSP)

## Repository Structure
